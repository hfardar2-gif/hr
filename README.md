# سامانه هوشمند سرمایه انسانی

نمونه تعاملی «حاکمیت داده سرمایه‌های انسانی» برای یک شرکت صنعتی ۳۰۰ نفره.

## صفحات فعلی

- `/` — صفحه ورود و انتخاب نقش
- `/executive` — داشبورد تجمیعی مدیرعامل
- `/hr` — داشبورد جامع مدیر منابع انسانی

## نقش‌ها

- **مدیرعامل:** شاخص‌های کلان، روند سازمان، رتبه واحدها و تعداد موارد پرریسک؛ بدون نمایش اطلاعات فردی.
- **مدیر منابع انسانی:** تحلیل سازمان، واحد و فرد، کیفیت داده، اقدامات توسعه‌ای و موارد نیازمند توجه.

## منابع داده هدف

- اطلاعات پرسنلی: راهکاران
- ورود و خروج: دنیای پردازش
- ارزیابی عملکرد: Excel
- آموزش و معاینات دوره‌ای: داده‌های تکمیلی منابع انسانی

## اجرای محلی

```bash
npm run install:ci
npm run dev
```

ساخت نسخه نهایی:

```bash
npm run build
```

## مستندات

شرح کامل سناریو، شاخص‌ها، دسترسی‌ها و نقشه توسعه در [گزارش طراحی و سناریوی سامانه](docs/PROJECT_REPORT_FA.md) قرار دارد.

## وضعیت فعلی

این نسخه یک دمو با داده‌های ساختگی است و هنوز به راهکاران، دنیای پردازش یا فایل‌های واقعی Excel متصل نشده است.
